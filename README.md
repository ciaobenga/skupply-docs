# Skupply Docs

Rep-facing documentation for how to use the Skupply Signal group bot — placing orders, discounts, recording payments, checking balances, receiving stock, returns, and inventory.

Built with [Mintlify](https://mintlify.com).

## Local preview

```
npx mintlify dev
```

## Deploying

Connect this repo to a Mintlify project at [mintlify.com](https://mintlify.com) — it builds and deploys automatically on every push to `main`.
