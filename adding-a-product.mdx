---
title: "Adding a Product"
description: "Introduce a brand-new product to the catalog from the group"
---

When a genuinely new product needs to be added to the catalog (not just receiving more stock of something that already exists), state its name, shorthand/SKU, and default price:

```
new product Rollie Ultra Light, SKU RUL, price 350
```

The bot creates it and confirms:

```
✅ New product added: Rollie Ultra Light (RUL) — default price $350
Added to 2 customer price sheet(s) — edit individual prices there as needed.
```

It's added to every existing customer's price sheet at that same default price — go into each customer's block in the sheet and adjust their individual price if it should be different.

<Note>
This is only for a product that doesn't exist yet. If you're reporting stock coming in for a product that's already in the catalog, that's [Receiving Stock](/receiving-stock) instead — just say `received 200 RUL paid by Danny`.
</Note>

## SKU already taken

Every SKU must be unique. If you pick one that's already in use, the bot tells you instead of creating a duplicate:

```
❌ Could not add product.
SKU "RUL" is already in use
```

Pick a different shorthand and try again.
